# When Waves Collide — site statique

Première reproduction du site public de When Waves Collide, prévue pour GitHub Pages. Le site conserve l’identité visuelle sombre, le menu, la photo de fond de l’accueil, les liens sociaux, les vidéos, les pages musique/bio/contact et les sorties Bandcamp.

## Fichiers

- `index.html` : contenu et vidéos intégrées
- `styles.css` : mise en page responsive
- `assets/accueil.jpg` : photographie de fond fournie pour la page d’accueil
- `script.js` : navigation mobile et section active

## Publication GitHub Pages

Créer un dépôt GitHub pour le groupe (par exemple `WhenWavesCollide`), y déposer ces fichiers à la racine, puis activer GitHub Pages depuis la branche `main`. Pour publier ensuite sur `www.whenwavescollide.com`, il faudra ajouter le domaine personnalisé dans les réglages Pages et faire pointer les enregistrements DNS du domaine vers GitHub Pages. Le site Google actuel restera actif jusqu’au changement DNS.

La photo de fond est incluse dans le dossier `assets`. Les vidéos sont intégrées depuis YouTube. Les concerts et le formulaire renvoient vers les espaces actuellement utilisés par le groupe.
